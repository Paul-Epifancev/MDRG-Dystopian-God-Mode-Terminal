# MDRG-Dystopian-God-Mode-Terminal
[EN] Pure Lua mod toolkit for My Dystopian Robot Girlfriend. Adds 22 utility items to shops for statistics viewing, instant boosters, remote shop access, and tools. [RU] Чистый Lua-мод для My Dystopian Robot Girlfriend. Добавляет 22 предмета в магазины: просмотр статистики, бустеры, удаленный доступ к лавкам и утилиты.
